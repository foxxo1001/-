# 数字分身上云指南（照做即可，约 10 分钟）

目标：把 `worker.js` 部署到 Cloudflare（免费），让网页通过它调用大模型。
做完后，API Key 只存在 Cloudflare 里，网页源码完全看不到。

## 一、拿大模型的 API Key（二选一）

**选 A：智谱 GLM（推荐，glm-4-flash 模型免费）**
1. 打开 https://open.bigmodel.cn 注册登录
2. 右上角头像 → 「API 密钥」→ 复制 Key（一长串字母数字）

**选 B：DeepSeek**
1. 打开 https://platform.deepseek.com 注册登录
2. 左侧「API Keys」→ 创建并复制

## 二、部署到 Cloudflare（免费账号即可）

1. 打开 https://dash.cloudflare.com 注册/登录
2. 左侧菜单 → 「Compute (Workers)」→ 「Create」→ 创建 Worker
3. 名字随便填（比如 `chat-proxy`）→ 「Deploy」先部署默认代码
4. 点 「Edit code / 编辑代码」→ 把里面内容**全删**，把本项目
   `cloudflare/worker.js` 的全部内容**粘贴进去** → 右上角 「Deploy」
5. 回到 Worker 设置页 → 「Settings → Variables and Secrets → Add」
   添加环境变量：

   | 类型 | 变量名 | 值 |
   |---|---|---|
   | Secret | `LLM_API_KEY` | 第一步复制的 Key |
   | Text | `LLM_API_URL` | 智谱填 `https://open.bigmodel.cn/api/paas/v4/chat/completions`；DeepSeek 填 `https://api.deepseek.com/chat/completions` |
   | Text | `LLM_MODEL` | 智谱填 `glm-4-flash`；DeepSeek 填 `deepseek-chat` |

6. 保存后，Worker 页面会显示地址，形如
   `https://chat-proxy.你的名字.workers.dev`

## 三、把地址填进主页

1. 用编辑器打开 `index.html`，找到这一行（在 `<script>` 开头附近）：
   ```
   const CHAT_API = '';
   ```
2. 把引号里换成你的 Worker 地址（就是 Worker 页面显示的那个，直接用）：
   ```
   const CHAT_API = 'https://chat-proxy.你的名字.workers.dev';
   ```
3. 保存，刷新网页 → 问分身一个知识库里没有的问题，能自然回答就成功了

## 四、发布

```
git add -A
git commit -m "接入真分身：云端中转 + 本地规则兜底"
git push
```

## 常见问题

- **问什么都退回本地规则答案**：说明网页没连上 Worker。检查 CHAT_API 地址是否填对、Worker 是否部署成功（浏览器直接打开 Worker 地址，显示 `{"error":"POST only"}` 就是活的）
- **报「缺少环境变量 LLM_API_KEY」**：第 5 步的 Secret 没添加或名字拼错
- **报「模型接口返回 401」**：Key 复制错了或没余额
- **想让本站更防刷**：目前 Worker 允许任何网站调用（免费额度内问题不大）；要收紧可把 CORS 里的 `*` 换成你的主页地址
